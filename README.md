# CSE One For All

> Kho lưu trữ bài tập lớn, đồ án và tài liệu học tập của các môn cơ sở và chuyên ngành thuộc khoa CSE.

Repository này tập hợp các bài thực hành theo nhiều hướng: cấu trúc dữ liệu và giải thuật, lập trình hệ thống, cơ sở dữ liệu, mạng máy tính, ngôn ngữ lập trình và trí tuệ nhân tạo.

## Cách sử dụng

Mỗi thư mục môn học là một dự án tương đối độc lập. Để biết cách biên dịch hoặc chạy một bài cụ thể:

1. Mở README hoặc tài liệu hướng dẫn bên trong thư mục môn học.
2. Kiểm tra file cấu hình và yêu cầu môi trường của từng bài.
3. Sử dụng Makefile, script biên dịch hoặc lệnh chạy được cung cấp trong thư mục tương ứng.

Các công nghệ xuất hiện trong repository gồm C++, Java, Python, MIPS Assembly, ứng dụng web và Cisco Packet Tracer.

## Ghi chú

Đây là kho lưu trữ phục vụ mục đích học tập. Một số bài có thể yêu cầu thư viện, trình biên dịch hoặc công cụ mô phỏng riêng; hãy ưu tiên hướng dẫn tại thư mục của bài đó.
