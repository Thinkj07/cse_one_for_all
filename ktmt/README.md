# Bài Tập Lớn Kiến Trúc Máy Tính (CO2008) - Nhóm 113

Repository này chứa mã nguồn cho bài tập lớn môn Kiến trúc máy tính (Học kỳ 241).

## Cấu trúc thư mục

### 1. Group (Bài tập nhóm)

Thư mục chứa mã nguồn bài tập chung của nhóm 113.

- **`Mn113.asm`**: Chương trình MIPS Assembly thực hiện thuật toán **Selection Sort**.
  - Đọc dữ liệu mảng số nguyên (10 phần tử) từ file nhị phân `INT10.BIN`.
  - Hiển thị từng bước sắp xếp ra màn hình console.
- **`INT10.BIN`**: File dữ liệu đầu vào cho chương trình sắp xếp.
- **`Bc_nhom113.pdf`**: Báo cáo bài tập lớn của nhóm.

### 2. Personal (Bài tập cá nhân)

Thư mục chứa bài tập riêng của sinh viên (MSSV: 2313284).

- **`Mn_2313284`**: Chương trình MIPS Assembly xử lý số thực.
  - Tạo ngẫu nhiên 3 số thực.
  - Định dạng và ghi vào file `SOLE.TXT` với độ chính xác lần lượt là 2, 3 và 4 chữ số sau dấu phẩy.
- **`macro.mac`**: File định nghĩa các macro hỗ trợ (dùng chung cho các chương trình).
- **`Bc_2313284.pdf`**: Báo cáo cá nhân.

## Yêu cầu hệ thống

- Chương trình được viết bằng MIPS Assembly.
- Công cụ mô phỏng đề xuất: **MARS (MIPS Assembler and Runtime Simulator)**.
