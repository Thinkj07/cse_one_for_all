# Computer Networking - TN CO3094 (251)

Repository này chứa các bài tập lớn (Assignment) của môn học Mạng máy tính.

## Cấu trúc thư mục

### 1. Assignment 1: HTTP Server & Web Application

- **Mô tả:** Triển khai HTTP Server, Proxy và ứng dụng web đơn giản.
- **Ngôn ngữ/Công nghệ:** Python, HTML/CSS/JS.
- **Thư mục chính:** `CO3094-weaprous/` chứa mã nguồn (backend, proxy daemon, frontend).

### 2. Assignment 2: Network Design For A Company

- **Mô tả:** Thiết kế hệ thống mạng cho doanh nghiệp (Multi-site network).
- **Công cụ:** Cisco Packet Tracer.
- **File chính:** `simulation.pkt` (File mô phỏng mạng).

## Yêu cầu cài đặt

- **Python 3.x** (cho Assignment 1).
- **Cisco Packet Tracer** (cho Assignment 2).
