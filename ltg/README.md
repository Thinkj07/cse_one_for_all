# Lập trình game

Thư mục này chứa 6 bài tập lớn phát triển game với độ khó tăng dần, từ tương tác cơ bản đến game 3D và nhiều người chơi.

## Nội dung bài tập

1. **BTL1 - Click and point game**: Xử lý tương tác trỏ và nhấp.
2. **BTL2 - Collision game**: Xử lý va chạm giữa các đối tượng trong game.
3. **BTL3 - 2D platform game**: Xây dựng game đi cảnh hai chiều.
4. **BTL4 - Board game/strategy game**: Phát triển board game hoặc game chiến thuật.
5. **BTL5 - Multiplayer**: Bổ sung chế độ nhiều người chơi cho BTL3 và BTL4.
6. **BTL6 - 3D game và multiplayer**: Kết hợp không gian 3D với tính năng nhiều người chơi.

Các bài được sắp xếp trong các thư mục [`1/`](1/) đến [`6/`](6/). Xem tài liệu và mã nguồn trong từng thư mục để biết yêu cầu cụ thể của bài.
