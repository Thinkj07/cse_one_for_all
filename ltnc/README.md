# LTNC_CO2039_242 - Lập Trình Nâng Cao

Dự án này chứa các bài tập lớn (Assignments) cho môn học Lập Trình Nâng Cao (CO2039) - Học kỳ 242.

## Cấu trúc dự án

### [Assignment 1](./Assignment1)

- **Ngôn ngữ**: Java
- **Nội dung**: Bài tập về Lập trình hướng đối tượng (OOP). Mô phỏng trận chiến giữa các nhân vật (Fighter, Monster) và quản lý đội hình.

### [Assignment 2](./Assignment2)

- **Ngôn ngữ**: Java (Maven Project)
- **Nội dung**: Ứng dụng theo dõi giá chứng khoán (Stock Monitor). Áp dụng các Design Patterns như Observer, Adapter để xử lý dữ liệu từ các sàn giao dịch (HOSE, HNX).

### [Assignment 3](./Assignment3)

- **Ngôn ngữ**: Python
- **Nội dung**: Xử lý Bảng ký hiệu (Symbol Table) và Kiểm tra lỗi tĩnh (Static Error) trong ngôn ngữ lập trình.

## Yêu cầu hệ thống

- **Java JDK**: Cần thiết cho Assignment 1 và 2.
- **Python**: Cần thiết cho Assignment 3.
